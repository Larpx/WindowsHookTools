# HookMonitor 用户使用说明

面向一般用户。技术实现、构建与扩展见 [开发说明](开发说明.md)。仓库入口见 [README](../README.md)。

## 这是什么

HookMonitor（仓库名 WindowsHookTools）是一款 Windows 桌面工具，用来观察本机进程是否出现可疑的截屏、进程枚举等行为，并给出威胁提示。默认以系统事件与句柄扫描为主，不依赖驱动，可在开启内存完整性的环境使用。

## 需要什么

| 项 | 说明 |
|----|------|
| 系统 | Windows 10（较新版本）或 Windows 11 |
| 架构 | 64 位 |
| 权限 | **管理员身份**运行（否则部分监控不可用） |
| 运行时 | .NET 10 |

## 程序大致怎么跑

1. 以管理员身份启动程序。  
2. 在主界面点击开始监控。  
3. 观察可疑进程列表与状态摘要。  
4. 选中某条记录查看检测原因与相关细节。  
5. 不需要时点击停止监控并退出。

## 怎么启动

- 从已发布的程序目录启动可执行文件，或按开发说明用命令行启动 GUI 工程。  
- 启动后若提示权限不足：关闭程序，右键选择「以管理员身份运行」再开。

## 主要功能怎么用

| 功能 | 怎么用 |
|------|--------|
| 开始 / 停止监控 | 主界面上的开始、停止按钮 |
| 查看可疑进程 | 列表会随扫描更新；注意状态栏中的可疑进程数量 |
| 查看详情 | 选中列表中的进程，查看威胁等级与检测原因 |
| 默认监控方式 | 默认使用系统事件追踪 + 句柄扫描；高级注入式拦截默认关闭，一般用户无需改动 |

威胁等级用颜色区分：分数越高越危险。常见合法工具（如任务管理器、系统截图工具）可能被减分或弱化提示，但仍建议结合自身使用场景判断。

## 使用建议

- 日常排查时保持默认开关即可，不必开启高级注入功能。  
- 监控期间尽量少改无关系统设置，便于对照「开始前后」的差异。  
- 若列表突然变长，先确认是否刚打开大量带截图、远程桌面、安全软件相关的程序。  
- 停止监控后再关闭程序，避免后台任务未收尾。

## 常见问题

| 现象 | 你可以怎么做 |
|------|----------------|
| 提示需要管理员权限 / 监控没反应 | 关闭后以管理员身份重新运行 |
| 列表为空 | 确认已点「开始」；再观察一段时间；确认本机确有相关可疑行为 |
| 正常软件也被标出 | 对照检测原因；若确认为自用合法工具，可忽略或事后再查 |
| 程序打不开 | 确认已安装 .NET 10，系统为 64 位 Windows |
| 想改扫描间隔等行为 | 见开发说明中的配置说明；一般用户保持默认即可 |
